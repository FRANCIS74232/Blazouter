## 📦 Overview

Blazouter brings modern routing to your Blazor applications. With features inspired by React Router, you gain more control over how your application navigates. You can use nested routes, built-in route guards, and lazy loading. It is compatible with Server, WebAssembly, and Hybrid (MAUI) hosting models.

## 🌟 Features

Blazouter offers several powerful features:

- **Nested Routes:** Create complex routing structures easily.
- **Built-in Route Guards:** Protect your routes and manage access based on user states.
- **Lazy Loading:** Optimize the app's performance by loading parts of your application as needed.
- **Type-Safe:** Enjoy strong typing, which reduces errors in development.
